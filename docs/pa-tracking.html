Plano de Ação: Matriz de Tags e Disparos no GTM

Implementação técnica: Google Analytics 4, Google Ads e Microsoft Clarity

1. Matriz Operacional do Container

Tag GTM Tipo Acionador / Regra Parâmetros Enviados
GA4 - Configuração GA4 Configuration All Pages (Initialization) page_location, page_title
GA4 - WhatsApp Click GA4 Event (click_whatsapp) Clique em links com wa.me ou api.whatsapp unidade_clicada, posicao_elemento, link_url
GA4 - Generate Lead GA4 Event (generate_lead) Evento Customizado form_lead_sucesso unidade, faixa_etaria, form_id
Google Ads - Conversão Lead Google Ads Conversion Evento Customizado form_lead_sucesso Conversion ID, Conversion Label
Google Ads - Conversão Wpp Google Ads Conversion Clique nos botões de WhatsApp Conversion ID, Conversion Label
Microsoft Clarity Custom HTML All Pages Captura de calor, gravações e cliques com raiva

2. Configurações Técnicas no GTM

Variáveis Personalizadas (DLV)

  • • leadData.unidade → Variável Camada de Dados
  • • leadData.faixa_etaria → Variável Camada de Dados
  • • leadData.form_id → Variável Camada de Dados
  • • Habilitar variáveis nativas: Click URL e Click Text

Regras dos Acionadores (Triggers)

  • Trig - Clique WhatsApp:
    Tipo: Apenas Links • Dispara se: Click URL contém wa.me
  • Trig - Sucesso Form Lead:
    Tipo: Evento Personalizado • Nome do evento: form_lead_sucesso

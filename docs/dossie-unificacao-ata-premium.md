## 4. Plano de Ação & Implementação Analítica (GTM + GA4 + Clarity)

### Etapa 1: Provisionamento e Injeção de Tags
1. Criar container web único no **Google Tag Manager (GTM)** e instalá-lo no `<head>` e `<body>` do novo site unificado.
2. Criar fluxo de dados web no **Google Analytics 4 (GA4)** e acionar a Tag de Configuração do GA4 via GTM em `Initialization - All Pages`.
3. Criar projeto no **Microsoft Clarity**, integrar nativamente com o GA4 e injetar a tag de script via GTM em `All Pages`.

### Etapa 2: Mapeamento da Camada de Dados (Data Layer)
Padronizar no código do novo site o disparo de evento estruturado no envio bem-sucedido de formulário:

```javascript
window.dataLayer = window.dataLayer || [];
window.dataLayer.push({
  event: 'form_lead_sucesso',
  leadData: {
    form_id: 'form_aula_experimental',
    unidade: 'Spotmarkt',
    faixa_etaria: 'Kids (7 a 13 anos)'
  }
});
